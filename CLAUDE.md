# Start here

The work queue is `docs/WORK-ORDERS.md`.

- Started with no specific task, or told to "run the queue": run `git fetch origin`, read
  `docs/WORK-ORDERS.md` on `origin/main`, and execute it as it says. Do not ask for confirmation;
  the file says when to stop.
- Given a different task by the owner: do that task and leave the queue alone.
